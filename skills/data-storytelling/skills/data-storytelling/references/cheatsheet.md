# Cheatsheet: decision rules and smells

Quick judgment calls for a critique. Every line should help decide something.

## If → then

| If… | Then… | Because… |
|-----|-------|----------|
| Asked to "fix this chart" with no context | Ask about audience, stakes, goal, and delivery first | Advice without context isn't useful |
| The person is still exploring | Leave it messy | Polish only pays off when explaining |
| It'll be read alone (email, report, dashboard) | Put more explanation on the page | No presenter to fill the gaps |
| It'll be presented live | Cut on-slide text | The speaker carries the narration |
| Tempted by an unusual chart | Use it only for a specialist audience or to reveal something hidden | Readers pay a learning cost first |
| The data supports several messages | Choose one for this audience and design for it | A graph that says three things says none |
| Nobody can state the point | Stop formatting; talk it through | Design can't rescue a missing message |
| The chart is clean but flat | Add contrast on the key data | Removing alone doesn't communicate |
| Everything is highlighted | Keep one accent and gray the rest | Emphasis is relative |
| The metric isn't what the audience owns | Restate it as cost, cash, risk, or growth | Tension comes from their stakes |
| No basis for a specific recommendation | Propose next steps | Ending with no action wastes the work |
| Refining a draft | Remove or simplify before adding | Subtraction usually wins |
| Unsure about a fact | Label it as an assumption and ask | Never invent data or context |

## Smells → likely fix

| Smell | Likely fix |
|-------|-----------|
| Legend off to the side | Label series directly at the line end or bar |
| Gridlines, border, `.00` everywhere | Defaults were never touched; run a declutter pass |
| Slide title is a topic ("Sales 2025") | Rewrite as a takeaway ("Sales recovered by May") |
| Rainbow of series colors | One accent and grays, or a single hue in shades |
| The important line looks like all the others | Make it thicker and darker, label it, gray the rest |
| Highlighted data ≠ what the title says | Align emphasis with the takeaway |
| The deck walks through the analysis process | Reorder around the audience's question; put the process in an appendix |
| Ends with "Questions?" and no ask | Add a recommendation or decision slide |
| Dense table on a presented slide | Pull out the one number that matters; move the table to the appendix |
| Every reply from the assistant just agrees | Ask it to challenge the assumptions |

## Order of work

context → message → visual → declutter → focus → words → story → challenge
